- **Theme**: Deep Charcoal & Void Black (`#07080A`, `#0E1017`, `#131620`).

- **Typography**: 
  - **Display / Headers**: *Syne* & *Space Grotesk* for oversized editorial impact.
  - **Body**: *Space Grotesk* / *Inter* for crisp legibility across viewports.
  - **Technical Meta**: *JetBrains Mono* for engineering credibility.
- **Interactive Tactile Features**:
  - **3D WebGL Centerpiece**: Real-time rotating wireframe icosahedron with inner core and orbiting particle constellation that responds dynamically to mouse coordinates.
  - **Custom Magnetic Cursor**: Lerping smooth cursor with hover scaling, interaction text, and auto-disable on touch devices.
  - **Web Audio API Sound Engine**: Subtle synthesizer clicks and hover pops for tactile feedback (with audio mute toggle).
  - **Noise Texture & Cyber Grid**: Subtle SVG noise overlay and animated perspective grids.
  - **Glassmorphism**: 1px subtle luminous borders with multi-layer backdrop blurs.

## 🛠️ Getting Started & Commands

Inside `agency-website/`:

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (with hot reloading)
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview the production build locally
npm run preview
```

Or double-click `start-website.bat` in the root folder!

## 📝 Customization Guide

- **Agency Name & Identity**: Update in `src/components/Navbar.tsx` and `src/components/Footer.tsx`.
- **Services Data**: Edit `src/data/servicesData.ts`.
- **Portfolio Case Studies**: Add or edit projects in `src/data/projectsData.ts`.
- **Company Statistics**: Update numbers and labels in `src/data/agencyStats.ts`.
- **Careers & Open Roles**: Add/remove positions in `src/data/careersData.ts`.
- **Form Submissions**: Stored automatically in browser `localStorage` (`valence_project_inquiries` and `valence_career_applications`). Can be pointed to a Formspree / Web3Forms / Resend API endpoint in `src/components/Contact.tsx`.
